# 🍔 Burger House

Sistema de pedidos para uma hamburgueria desenvolvido com **HTML, CSS e JavaScript**.

O objetivo do projeto foi criar uma aplicação simples, moderna e totalmente funcional para simular o funcionamento de um sistema de pedidos de uma lanchonete.

# 🚀 Funcionalidades

## 🍔 Catálogo de Produtos
- Listagem de produtos
- Pesquisa por nome
- Filtro por categoria
- Layout responsivo

## 🛒 Carrinho de Compras
- Adicionar produtos
- Aumentar quantidade
- Diminuir quantidade
- Remover itens
- Cálculo automático do total

## 🧀 Sistema de Adicionais
Alguns produtos permitem selecionar adicionais antes de serem adicionados ao carrinho.

Exemplos:
- Bacon
- Cheddar
- Ovo

O preço é atualizado automaticamente conforme os adicionais escolhidos.

---

## 📋 Finalização do Pedido

O cliente pode informar:

- Nome
- Telefone
- Tipo do pedido (Entrega ou Retirada)
- Endereço
- Forma de pagamento

Antes da confirmação é exibido um resumo completo do pedido.

---

## 📚 Histórico de Pedidos

Após finalizar um pedido, o sistema mantém um histórico contendo:

- Nome do cliente
- Telefone
- Valor total
- Data do pedido

---

## ⚙️ Painel Administrativo

Área exclusiva para gerenciamento dos produtos.

Permite:

- Cadastrar produtos
- Editar produtos
- Excluir produtos
- Visualizar todos os produtos cadastrados

---

## 🌙 Modo Escuro

O sistema possui suporte ao modo escuro (Dark Mode), proporcionando uma interface mais confortável para utilização em ambientes com pouca iluminação.

---

## 📱 Responsividade

O sistema foi desenvolvido para funcionar em diferentes tamanhos de tela, adaptando o layout para computadores, tablets e celulares.

---

# 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage

---

# 💾 Armazenamento

Os dados são armazenados utilizando o **LocalStorage** do navegador.

São armazenados:

- Carrinho
- Histórico de pedidos
- Tema (Modo Claro/Escuro)
